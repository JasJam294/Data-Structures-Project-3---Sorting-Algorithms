# Data-Structures-Project-3---Sorting-Algorithms
C++ Project for 4 different sorting algorithms


## Used PowerShell to create input files 

(1..100) -join ' ' | Out-File -Encoding ascii input1.txt
(100..1) -join ' ' | Out-File -Encoding ascii input1_rev.txt

(1000..1) -join ' ' | Out-File -Encoding ascii input2_rev.txt
(1..10000) -join ' ' | Out-File -Encoding ascii input3.txt
(10000..1) -join ' ' | Out-File -Encoding ascii input3_rev.txt
